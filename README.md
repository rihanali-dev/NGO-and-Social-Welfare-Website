# 🤝 Umeed Social Welfare Foundation Website

A modern, responsive, and interactive website designed for an NGO to promote social welfare initiatives, showcase community activities, and enable online donations and volunteer registrations.

Developed as a web development project demonstrating the fundamental application of **HTML5**, **CSS3**, and vanilla **JavaScript**.

---

## 📌 Problem Statement Overview
**Topic:** NGO and Social Welfare Website  
**Objective:** Develop a fully functional, responsive, and user-friendly web interface to:
- Highlight social welfare drives (Child Education, Hunger Relief, Rural Healthcare).
- Showcase on-ground impact through interactive metrics.
- Encourage community engagement through donation and volunteer registration forms with client-side JavaScript handling.

---

## ✨ Features

- **Responsive Navigation Bar:** Sticky header with quick-jump links across all key sections.
- **Hero Banner:** Compelling mission statement with call-to-action buttons.
- **Impact Metrics Showcase:** Clean stats cards highlighting real-time milestones (Meals served, Children educated, etc.).
- **Interactive Activity Gallery:** Modern card-based UI displaying primary social projects.
- **Client-Side Form Handling (JavaScript):**
  - **Donation Portal:** Handles donor data and triggers custom confirmation alerts without reloading the page (`event.preventDefault()`).
  - **Volunteer Registration:** Captures participant interest and resets dynamically upon valid submission.
- **Responsive Layout:** Optimized for mobile phones, tablets, and desktop displays using CSS Grid and Flexbox.

---

## 🛠️ Tech Stack Used

| Technology | Purpose |
| :--- | :--- |
